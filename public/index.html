What comes back

  • The accreditation symbol, with your certificate number beneath it if you enter one: a small copy to the left of each accredited parameter's name, and a full-size one at the foot beside the QR.
  • A QR code that opens a download of this exact sealed file. The link is signed, so it cannot be guessed from another report's.
  • "Page X of Y" on every sheet.
  • The original untouched. Your upload is kept beside the sealed copy; the text, fonts and layout inside are never re-flowed.

The file is read as soon as you drop it, so the parameter names can be found. It stays on this server only.
